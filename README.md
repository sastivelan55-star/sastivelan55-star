## `./projects.sh`

### 🛡️ [Clarifyx](https://github.com/sastivelan55-star/Clarifyx) — AI-Based Digital Threat Detection System
Web app that analyzes phishing links, suspicious messages, manipulated media and AI-generated voice indicators, then returns a risk score with supporting details.
- Flask REST APIs return real-time threat analysis as JSON
- Backend logic combines multiple threat indicators into one risk score

`React` `Python` `Flask` `REST APIs` `Cybersecurity`

### ⛰️ [Malai Vizhi](https://github.com/sastivelan55-star/Malai-vizhi) — Landslide Risk Monitoring & Early Warning System
Web platform that combines rainfall, soil moisture, terrain/slope and historical hazard data to assess landslide risk.
- Flask APIs run a multi-factor empirical risk analysis and serve geospatial data
- Interactive Leaflet.js map for risk zones and user hazard reports
- Offline-first Progressive Web App (PWA)

`React` `TypeScript` `Python` `Flask` `SQLite` `Leaflet.js` `PWA`
